# Invariants: records database and full-text search

Covers `internal/records`, the record tables and the full-text index in `internal/evidence`, the P-series checks of `case verify`, the `records` commands and scale. Part of the [forensic invariants](../invariants.md), which say how to add or change a row. Each row is enforced by the tests it names: keep them green.
