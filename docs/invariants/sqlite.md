# Invariants: SQLite library, decoder and record recovery

Covers `internal/sqlitefile`, the table decoder `internal/decode/sqlitedb` (with `cellx`, `rowrun` and `recrun`) and record recovery in `internal/dbrecover` (`sqlite recover`). Part of the [forensic invariants](../invariants.md), which say how to add or change a row. Each row is enforced by the tests it names: keep them green.
