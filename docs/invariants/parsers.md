# Invariants: parsers and the parse host

Covers the parse contract and host (`internal/parse`, `internal/artparse`), `internal/recordtypes`, the decoders `decode/ts`, `decode/plist`, `decode/typedstream`, `decode/iosbackup` and `decode/tl`, and the artifact parsers in `internal/parsers`. Part of the [forensic invariants](../invariants.md), which say how to add or change a row. Each row is enforced by the tests it names: keep them green.
